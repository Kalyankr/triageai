# 🚨 TriageAI — Bystander Emergency Triage

**Offline · Multilingual · Powered by Gemma 4**

> *"The next life saved should not depend on cell signal."*

TriageAI is a bystander first-aid triage system built for the **Gemma 4 Good Hackathon 2026**.
It classifies emergencies using the international START triage protocol (RED/YELLOW/GREEN/BLACK)
and provides step-by-step guidance in multiple languages — even without internet.

## Features

- 🔴🟡🟢⚫ **START Triage Protocol** — same system used by paramedics worldwide
- 🌍 **Multilingual** — English, Spanish, Hindi, Arabic, French, Portuguese, Chinese
- 📸 **Multimodal** — describe OR photograph the emergency
- 📵 **Offline-first** — fully functional with no internet (rule-based engine fallback)
- ⚡ **Native function calling** — Gemma 4's built-in tool use for structured pipeline
- 🧠 **Thinking mode** — step-by-step medical reasoning

## How to Use

1. Choose your language (or leave on Auto-detect)
2. Upload a photo of the emergency (optional)
3. Describe what you see
4. Click **TRIAGE NOW** for immediate guidance

Or use one of the **Quick Scenario** buttons to try a pre-loaded example.

## ⚠️ Disclaimer

This is an AI assistant and **NOT a substitute for professional medical care**.
Always call emergency services (911 / 112 / 999) for life-threatening situations.
